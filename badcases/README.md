# myClaw Badcases

This directory records observed failures during MVP-to-harness iteration.

Each badcase should capture:

- Symptom: what the user saw.
- Reproduction: the shortest interaction that triggers it.
- Root cause: the current harness gap.
- Impact: why it matters.
- Candidate fixes: prompt, state, tool, eval, or orchestration changes to test.
- Regression test idea: how to prevent the issue from silently returning.
