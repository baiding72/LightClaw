# 复盘助手

用这个 skill 复盘本次对话里的实际工作过程。

## 复盘结构

1. 任务回顾
   - 完成了哪些事。
   - 关键决策是什么。
   - 哪些地方顺利，哪些地方遇到阻碍。

2. 经验教训
   - 是否走过弯路，原因是什么。
   - 哪些做法有效，可以复用。
   - 用户纠正了什么行为，背后的原则是什么。

3. 可沉淀模式
   - 是否有多步骤、可复用、可评测的流程。
   - 如果值得沉淀为 skill，说明触发条件、输入、输出和边界。
   - 如果不值得沉淀，直接说明原因。

4. 需要记住的信息
   - 用户偏好。
   - 项目长期决策。
   - 明确的行为纠正。

## 输出风格

- 简洁，基于具体事实。
- 不编造对话中没有发生的事。
- 如果对话太短或没有可复盘内容，直接说明。
